# NEXUS App（React Native 重写版）— 手机端操作指南

## 现在做到哪一步了

已经搭好的骨架：
- 底部四个 Tab：今日 / 应用 / 私信 / 我的（对应网页版）
- 「我的」页面接了真实的登录/退出登录功能，直接连你现有的 Supabase 项目
- 数据库、账号、RLS 策略全部复用网页版的，不用重新搭后端

其他功能（私信聊天、社区发帖、群组、管理后台、竹知了游戏……）还没做，后面一个一个来。

## 第一步：把项目传到 GitHub

跟你之前传网页版一样的操作，新建一个仓库（比如叫 `nexus-app-native`，跟网页版那个仓库分开，别混在一起），把这次发你的所有文件按原来的文件夹结构传上去。

## 第二步：注册 Expo 账号

手机浏览器打开 `expo.dev`，注册一个账号（邮箱注册就行）。这个账号是用来云端编译你的 App 的，免费额度对你现在这个阶段够用。

## 第三步：把 Supabase 的密钥填进去

打开 `src/lib/supabase.js`，把 `SUPABASE_ANON_KEY` 那一行的占位文字换成你网页版 `index.html` 里 `SUPABASE_KEY` 那个真实的值（直接复制过去）。

## 第四步：连接 GitHub 仓库到 Expo，触发云端编译

1. 登录 `expo.dev`，创建一个新项目，选择"从 GitHub 导入"
2. 选中你刚才建的那个仓库
3. Expo 会自动识别出这是个 Expo 项目，提示你可以直接构建
4. 选择构建安卓的 **preview** 版本（对应 `eas.json` 里配置的那个，产出的是可以直接安装的 apk 文件，不用先上架应用商店才能装）
5. 提交构建，等云端编译完成（一般几分钟到十几分钟，取决于排队情况）
6. 编译完成后，Expo 网页上会给一个下载链接，手机上直接点开下载 apk，安装即可

## 关于 iOS

iOS 的安装包必须要有苹果开发者账号（一年 688 元人民币）才能真机安装或者上架，这个费用没法绕开，是苹果的规定，不是 Expo 的限制。安卓这边免费，可以先把安卓这条路跑通，iOS 等你决定要不要投入这个费用了再说。
